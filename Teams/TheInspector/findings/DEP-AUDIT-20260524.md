### P1 — Critical Severity

#### DEP-001: Handlebars JavaScript Injection (Multiple CVEs)
- **Severity:** P1 (Critical)
- **Category:** CVE - JavaScript Injection / Template Injection
- **Package:** `handlebars` ≤4.7.8
- **Location:** Source/Backend (transitive via npm dependencies)
- **CVE Details:**
  - **GHSA-2qvq-rjwj-gvw9**: Prototype Pollution → XSS via partial template injection (CVSS 4.7)
  - **GHSA-3mfm-83xf-c92r**: AST Type Confusion → JavaScript injection (CVSS 8.1)
  - **GHSA-2w6w-674q-4c4q**: AST Type Confusion (no partial) (CVSS 9.8 — *highest*)
  - **GHSA-7rx3-28cr-v5wh**: Prototype method access bypass (CVSS 4.8)
  - **GHSA-442j-39wm-28r2**: Property access validation bypass (CVSS 3.7)
  - **GHSA-xhpv-hc6g-r9c6**: AST type confusion with dynamic partial (CVSS 8.1)
  - **GHSA-9cx6-37pm-9jff**: DoS via malformed decorator syntax (CVSS 7.5)
  - **GHSA-xjpj-3mr7-gcpf**: JavaScript injection in CLI precompiler (CVSS 8.2)

- **Affected Range:** ≥4.0.0 ≤4.7.8
- **Root Cause:** Handlebars template injection vulnerabilities allow attackers to inject arbitrary JavaScript via template manipulation or prototype pollution
- **Fix:** Update handlebars to ≥4.7.9
  ```bash
  cd Source/Backend && npm update handlebars --depth=999
  ```
- **Risk Assessment:** 
  - ✓ Transitive dependency (not directly declared)
  - ⚠️ Multiple CVEs with high CVSS scores
  - ⚠️ Could allow RCE if handlebars is used for user-controlled template rendering
- **Recommendation:** **Immediate** — Apply patches within 24 hours

#### DEP-004: Path-to-Regexp ReDoS (Regular Expression Denial of Service)
- **Severity:** P2 (High)
- **Category:** CVE - Denial of Service
- **Package:** `path-to-regexp` <0.1.13
- **Location:** 
  - platform/orchestrator
  - portal/Backend
- **CVE Details:**
  - **GHSA-37ch-88jc-xwx2**: Multiple route parameters cause catastrophic regex backtracking (CVSS 7.5)
  - **CWE-1333** (Inefficient Regular Expression Complexity)

- **Attack Vector:** Craft malicious URL with repeated parameter patterns → CPU exhaustion → service becomes unresponsive
  - Example: `/api/:x/:x/:x/:x/...` with overlapping path data
  
- **Affected Range:** <0.1.13
- **Transitivity:** Transitive (via express routing)
- **Risk Assessment:**
  - ✗ Easy to exploit (just a crafted URL)
  - ✗ Affects core routing infrastructure
  - ✗ Both orchestrator and portal backend vulnerable

- **Fix:** Express will pull in fixed path-to-regexp; verify your express versions
  ```bash
  npm update express path-to-regexp
  ```
- **Recommendation:** **High Priority** — Apply within 1 week; test URL fuzzing after patch
