## Critical Priority (P1) Findings

### DEP-001: Handlebars JavaScript Injection (AST Type Confusion)
- **Severity:** P1 (Critical)
- **Category:** CVE - Remote Code Execution
- **Package:** handlebars
- **Version Range Affected:** >=4.0.0 <=4.7.9
- **Workspaces:** Source/Backend (node_modules/handlebars)
- **CVEs:** GHSA-2w6w-674q-4c4q (CVSS 9.8), GHSA-3mfm-83xf-c92r, GHSA-8r5x-fm3f-whwj
- **Detail:** Multiple critical injection vulnerabilities via AST type confusion. Attacker can inject arbitrary JavaScript through template manipulation. Also includes prototype pollution and partial template injection vectors.
- **Impact:** Arbitrary code execution on server rendering context
- **Fix:** `npm update handlebars` (upgrade to >=4.7.10 for Source/Backend)
- **Cross-ref:** [ESCALATE → TheGuardians] - RCE risk in template rendering layer

---

### DEP-002: proxy-addr IPv4-Mapped IPv6 IP Spoofing
- **Severity:** P1 (Critical)
- **Category:** CVE - Authentication/Authorization Bypass
- **Package:** proxy-addr
- **Version Range Affected:** >=1.1.0 <2.0.8
- **Workspaces:** Source/Backend, platform/orchestrator (via express)
- **CVE:** GHSA-jqcg-44mw-7w3h (CVSS 9.1)
- **Detail:** IPv4-mapped IPv6 addresses can bypass IP trust subnet validation. Attacker can spoof their source IP to pass trust checks, bypassing access control.
- **Impact:** Authentication bypass, unauthorized access to protected endpoints
- **Fix:** `npm update proxy-addr` (upgrade to >=2.0.8)
- **Cross-ref:** [ESCALATE → TheGuardians] - Security boundary violation
