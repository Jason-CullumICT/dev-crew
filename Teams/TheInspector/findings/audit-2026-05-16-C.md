### QO-001: Traceability Enforcer Has a Blind Spot — portal/ Completely Unscanned
- **Severity:** P1
- **Category:** spec-drift / architecture-violation
- **File:** `tools/traceability-enforcer.py:76-83`
- **Detail:** The enforcer scans only `["Source", "E2E"]`. The primary application — `portal/Backend/` and `portal/Frontend/` — implements FR-001 through FR-069 (the whole dev-workflow-platform spec), all FR-dependency-*, all FR-DUP-*, and all FR-070+ image requirements. The net effect is that the main product has no enforced traceability gate.

  Confirmed via:
  ```
  python3 tools/traceability-enforcer.py --plan dev-workflow-platform

  # (All are in portal/, which is not scanned)
  ```
- **Recommendation:** Add `"portal"` to the `source_dirs` list in `tools/traceability-enforcer.py` line 68: `source_dirs = ["Source", "E2E", "portal"]`. Also update `inspector.config.yml` `source.dirs` to include `portal/`.
- **Cross-ref:** TheFixer for the one-line fix; affects all QA gates.

### QO-006: DB Connection Acquired in Route Handlers (51 occurrences, 9 files)
- **Severity:** P3
- **Category:** architecture-violation
- **Files:** All route files in `portal/Backend/src/routes/`:
  - `bugs.ts` (14 calls), `featureRequests.ts` (15), `cycles.ts` (9), `pipelines.ts` (5), `dashboard.ts` (2), `learnings.ts` (2), `teamDispatches.ts` (2), `features.ts` (1), `search.ts` (1)
- **Detail:** Architecture rule: "No direct DB calls from route handlers — use the service layer." Every route handler calls `const db = getDb()` then passes `db` into service functions. The actual SQL is in the services (good), but acquiring the connection in the route violates the pattern. Services should call `getDb()` internally, keeping the route layer free of any DB awareness.
  
  Example (`portal/Backend/src/routes/bugs.ts:38-39`):
  ```ts
  const db = getDb();
  const bugs = listBugs(db, { status, severity });
  ```
  Should be:
  ```ts
  const bugs = listBugs({ status, severity });  // service owns getDb()
  ```
- **Recommendation:** Refactor service function signatures to call `getDb()` internally. Routes should pass only domain arguments. This is a systematic refactor across all service files — coordinate via TheFixer with backend-coder.
- **Cross-ref:** TheFixer.
