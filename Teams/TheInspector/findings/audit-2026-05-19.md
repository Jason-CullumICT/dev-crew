## Critical Findings (P1)

### DEP-001: Protobufjs Arbitrary Code Execution
- **Severity:** P1 (CRITICAL)
- **Category:** cve
- **Package:** `protobufjs`
- **Affected Versions:** `<=7.5.5`
- **Files:** 
  - `platform/orchestrator/package.json`
  - `portal/Backend/package.json`
- **CVEs:**
  - GHSA-xq3m-2v4x-88gg: Arbitrary code execution (CVSS 9.8)
  - GHSA-66ff-xgx4-vchm: Code injection via bytes field defaults (High severity)
  - GHSA-2pr8-phx7-x9h3: Denial of service (Moderate)
  - GHSA-fx83-v9x8-x52w: Prototype injection (Moderate)
  - GHSA-75px-5xx7-5xc7: Code generation gadget (High, CVSS 8.1)
  - GHSA-jvwf-75h9-cwgg: Process-wide DoS (High, CVSS 7.5)
  - GHSA-685m-2w69-288q: Unbounded recursion DoS (High, CVSS 7.5)
  - GHSA-q6x5-8v7m-xcrf: Overlong UTF-8 decoding (Moderate)
- **Detail:** Protobufjs versions <=7.5.5 contain multiple code injection vulnerabilities that allow arbitrary code execution. The most critical issue (GHSA-xq3m-2v4x-88gg) has a CVSS score of 9.8 and requires no user interaction.
- **Impact:** An attacker can execute arbitrary code in the application context through specially crafted protobuf messages or configuration.
- **Fix:** `npm update protobufjs` to >=7.5.6 in both locations
- **Cross-ref:** [ESCALATE → TheGuardians] — Arbitrary code execution is a critical security vulnerability requiring immediate remediation.

### DEP-002: Handlebars JavaScript Injection via AST Type Confusion
- **Severity:** P1 (CRITICAL)
- **Category:** cve
- **Package:** `handlebars`
- **Affected Versions:** `4.0.0 - 4.7.8`
- **File:** `Source/Backend/package.json` (indirect dependency)
- **CVEs:** 8 different CVEs
  - GHSA-2w6w-674q-4c4q: JavaScript injection (CVSS 9.8, CRITICAL)
  - GHSA-3mfm-83xf-c92r: AST type confusion via @partial-block (CVSS 8.1, High)
  - GHSA-xhpv-hc6g-r9c6: JavaScript injection via dynamic partial (CVSS 8.1, High)
  - GHSA-9cx6-37pm-9jff: DoS via malformed decorator syntax (CVSS 7.5, High)
  - GHSA-xjpj-3mr7-gcpf: JavaScript injection in CLI precompiler (CVSS 8.2, High)
  - GHSA-2qvq-rjwj-gvw9: Prototype pollution XSS (CVSS 4.7, Moderate)
  - GHSA-7rx3-28cr-v5wh: Prototype method access control gap (CVSS 4.8, Moderate)
  - GHSA-442j-39wm-28r2: Property access validation bypass (CVSS 3.7, Low)
- **Detail:** Multiple code injection vulnerabilities in Handlebars allow attackers to execute arbitrary JavaScript code through template manipulation.
- **Impact:** Attackers can inject malicious code into templates that get executed server-side, potentially leading to data theft or server compromise.
- **Fix:** `npm update handlebars` to >=4.7.9 (or latest 4.x)
- **Cross-ref:** [ESCALATE → TheGuardians] — JavaScript injection in template engine is a critical vulnerability.

## High Priority Findings (P2)

### DEP-003: path-to-regexp Regular Expression Denial of Service
- **Severity:** P2 (HIGH)
- **Category:** cve
- **Package:** `path-to-regexp`
- **Affected Versions:** `<0.1.13`
- **Files:**
  - `platform/orchestrator/package.json` (indirect)
  - `portal/Backend/package.json` (indirect)
- **CVE:** GHSA-37ch-88jc-xwx2 (CVSS 7.5)
- **Detail:** path-to-regexp is vulnerable to ReDoS when multiple route parameters are combined. An attacker can craft a request that causes the regex engine to consume excessive CPU and memory.
- **Impact:** Denial of Service attacks against Express-based routing; application becomes unresponsive.
- **Fix:** Update transitive dependency chain (via express/framework updates). Verify `path-to-regexp` is >=0.1.13 in lock files.
- **Cross-ref:** [CROSS-REF: red-teamer] — Exploitable DoS vector in production routes.

### DEP-004: Picomatch ReDoS and Prototype Pollution
- **Severity:** P2 (HIGH)
- **Category:** cve
- **Package:** `picomatch`
- **Affected Versions:** `<2.3.2` or `4.0.0 - 4.0.3`
- **File:** `portal/Frontend/package.json` (indirect, via tailwindcss/build tools)
- **CVEs:**
  - GHSA-c2c7-rcm5-vvqj: ReDoS via extglob quantifiers (CVSS 7.5, High)
  - GHSA-3v7f-55p6-f55p: Method injection in POSIX character classes (CVSS 5.3, Moderate)
- **Detail:** Picomatch contains ReDoS vulnerabilities and prototype pollution issues. Build-time exposure (used by file watching tools).
- **Impact:** Denial of Service during frontend development/build; could affect CI/CD pipeline or development environment.
- **Fix:** `npm update picomatch` to >=2.3.2 (and <4.0.0) or >=4.0.4
- **Note:** This is a dev dependency, impact is limited to development/build environment.

### DEP-005: OpenTelemetry SDK Prometheus Exporter Crash
- **Severity:** P2 (HIGH)
- **Category:** cve
- **Package:** `@opentelemetry/sdk-node`, `@opentelemetry/auto-instrumentations-node`
- **Affected Versions:**
  - `@opentelemetry/sdk-node` <0.217.0
  - `@opentelemetry/auto-instrumentations-node` <0.75.0
- **File:** `portal/Backend/package.json`
- **CVE:** GHSA-q7rr-3cgh-j5r3 (CVSS 7.5, High)
- **Detail:** Prometheus metrics exporter crashes when receiving malformed HTTP requests. An attacker can craft requests that kill the metrics endpoint, potentially affecting observability and uptime.
- **Impact:** Application observability loss; prometheus scraping fails; DoS on metrics endpoint.
- **Fix:** 
  - `npm update @opentelemetry/sdk-node` to >=0.217.0
  - `npm update @opentelemetry/auto-instrumentations-node` to >=0.75.0

## Moderate Priority Findings (P3)

### DEP-006: Vite Path Traversal in Optimized Deps `.map` Handling
- **Severity:** P3 (MODERATE)
- **Category:** cve
- **Package:** `vite`
- **Affected Versions:** `<=6.4.1`
- **Files:**
  - `Source/Frontend/package.json`
  - `platform/orchestrator/package.json`
  - `portal/Backend/package.json`
  - `portal/Frontend/package.json`
- **CVE:** GHSA-4w7w-66w2-5vf9
- **Detail:** Vite development server allows path traversal via source map handling. An attacker can craft URLs to access files outside the intended directory.
- **Impact:** Information disclosure during development; potential exposure of sensitive files (env files, configs). Limited to dev environment.
- **Fix:** `npm update vite` to latest (>=6.4.2 or latest 6.x/8.x)
- **Note:** Affects dev dependencies; risk is limited to development environment.

### DEP-007: PostCSS XSS via Unescaped `</style>`
- **Severity:** P3 (MODERATE)
- **Category:** cve
- **Package:** `postcss`
- **Affected Versions:** `<8.5.10`
- **Files:**
  - `Source/Frontend/package.json`
  - `portal/Backend/package.json`
  - `portal/Frontend/package.json`
- **CVE:** GHSA-qx2v-qp2m-jg93 (CVSS 6.1)
- **Detail:** PostCSS fails to properly escape `</style>` tags in CSS output. If user-controlled content is injected into CSS, it could break out of the style tag and execute JavaScript.
- **Impact:** Potential for XSS if CSS includes user-controlled content.
- **Fix:** `npm update postcss` to >=8.5.10

### DEP-008: esbuild Development Server CORS Bypass
- **Severity:** P3 (MODERATE)
- **Category:** cve
- **Package:** `esbuild`
- **Affected Versions:** `<=0.24.2`
- **Files:**
  - `Source/Frontend/package.json`
  - `portal/Backend/package.json`
  - `portal/Frontend/package.json`
- **CVE:** GHSA-67mh-4wv8-2f99 (CVSS 5.3)
- **Detail:** esbuild development server allows any website to send requests and read responses, bypassing CORS. Dev environment only.
- **Impact:** During development, attacker website could interact with local dev server.
- **Fix:** This is typically fixed via vite update (which bundles esbuild)

### DEP-009: ws Uninitialized Memory Disclosure
- **Severity:** P3 (MODERATE)
- **Category:** cve
- **Package:** `ws` (WebSocket library)
- **Affected Versions:** `8.0.0 - 8.20.0`
- **Files:**
  - `Source/Frontend/package.json`
  - `portal/Frontend/package.json`
- **CVE:** GHSA-58qx-3vcg-4xpx (CVSS 4.4)
- **Detail:** ws WebSocket library can leak uninitialized memory in certain conditions. Low-probability exposure.
- **Impact:** Potential information disclosure from memory buffers.
- **Fix:** `npm update ws` to >=8.20.1

### DEP-010: Brace Expansion Process Hang
- **Severity:** P3 (MODERATE)
- **Category:** cve
- **Package:** `brace-expansion`
- **Affected Versions:** `<1.1.13`
- **File:** `Source/Backend/package.json` (indirect)
- **CVE:** GHSA-f886-m6hf-6m8v (CVSS 6.5)
- **Detail:** brace-expansion with zero-step sequences causes process hang and memory exhaustion. Can be triggered via malformed input to glob operations.
- **Impact:** DoS via untrusted input to glob operations.
- **Fix:** Transitive dependency update (typically via minimatch or glob updates)
