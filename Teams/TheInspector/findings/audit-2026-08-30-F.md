## Executive Summary

The dev-crew project contains **99 known vulnerabilities** across 6 npm workspaces (1,801 total dependencies). **Four critical findings** require immediate remediation before any production deployment:

2. **protobufjs@<=7.6.4** - Arbitrary code execution (CVSS 9.8)

## Critical Findings (P1)

### DEP-001: handlebars RCE
- **Package:** handlebars@4.0.0-4.7.8
- **Location:** Source/Backend
- **CVSS:** 9.8 (Critical)
- **CVEs:** GHSA-2w6w-674q-4c4q, GHSA-3jxf-hc6g-r9c6, GHSA-2qvq-rjwj-gvw9, GHSA-7rx3-28cr-v5wh, GHSA-442j-39wm-28r2, GHSA-xq3m-2v4x-88gg
- **Impact:** Remote code execution via template compilation
- **Fix:** Update to >=4.7.9 OR remove if unused
- **Status:** NOT YET FIXED

### DEP-002: protobufjs RCE
- **Package:** protobufjs@<=7.6.4
- **Location:** platform/orchestrator (via @grpc/grpc-js, OpenTelemetry)
- **CVSS:** 9.8 (Critical)
- **CVE:** GHSA-xq3m-2v4x-88gg
- **Impact:** Arbitrary code execution when parsing untrusted .proto files
- **Fix:** Update to >=7.6.5
- **Status:** NOT YET FIXED

### DEP-003: vitest RCE
- **Package:** vitest@<3.2.6
- **Locations:** Source/Frontend (@2.0.5), portal/Frontend (@1.4.0)
- **CVSS:** 9.8 (Critical)
- **CVE:** GHSA-5xrq-8626-4rwp
- **Impact:** Local privilege escalation via UI server (no auth required)
- **Fix:** Update to >=3.2.6 (or >=4.1.11 for major upgrades)
- **Status:** NOT YET FIXED

### DEP-004: OpenTelemetry Supply Chain Risk
- **Package:** @opentelemetry/auto-instrumentations-node@0.40.0
- **Location:** portal/Backend
- **Impact:** Cascades ~40 instrumentation packages with 10+ vulns in portal/Backend alone
- **Fix:** Replace with explicit instrumentation pins OR upgrade to constrained version
- **Status:** NOT YET FIXED
