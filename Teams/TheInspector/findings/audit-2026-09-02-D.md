## Critical Vulnerabilities (P1)

### DEP-001: protobufjs Arbitrary Code Execution
- **Severity:** P1 (CRITICAL)
- **Category:** CVE
- **Package:** protobufjs
- **Affected Project:** portal/Backend
- **Vulnerable Range:** <7.5.5
- **CVE:** CVE-2024-6249 (GHSA-xq3m-2v4x-88gg)
- **CVSS Score:** 9.8 / Critical
- **CWE:** CWE-94 (Arbitrary Code Execution)
- **Impact:** Arbitrary code execution via deserialization of untrusted Protocol Buffer messages. An attacker can craft malicious proto files to execute arbitrary code during parsing.
- **Root Cause Chain:** 
  - portal/Backend uses `@opentelemetry/auto-instrumentations-node@0.40.0`
  - → requires `@grpc/proto-loader` with protobufjs <7.5.5
  - → protobufjs versions <7.5.5 have unsafe deserialization
- **Fix:** Upgrade `@opentelemetry/auto-instrumentations-node` to ≥0.80.0 (major version bump)
- **Cross-ref:** [ESCALATE → TheGuardians] — This is an RCE vector and must be treated as P0 if this backend handles untrusted gRPC messages.

## High-Severity Vulnerabilities (P2)

### DEP-002: brace-expansion Denial of Service (Multiple CVEs)
- **Severity:** P2 (HIGH)
- **Category:** CVE (ReDoS / DoS)
- **Package:** brace-expansion
- **Affected Projects:** Source/Backend, Source/Frontend
- **Vulnerable Range:** <1.1.18
- **CVEs:**
  - GHSA-f886-m6hf-6m8v: Zero-step sequence causes process hang
  - GHSA-3jxr-9vmj-r5cp: DoS via exponential-time expansion (5.3 CVSS)
  - GHSA-mh99-v99m-4gvg: Out-of-memory crash via unbounded expansion (7.5 CVSS)
  - GHSA-rgw5-rvv9-x895: Unbounded intermediate arrays bypass (7.5 CVSS)
- **CVSS Range:** 5.3–7.5
- **CWE:** CWE-400, CWE-407, CWE-770
- **Impact:** An attacker providing crafted glob patterns (e.g., via CLI tools or build scripts) can cause memory exhaustion and process termination. Affects build-time tooling.
- **Indirect Dependency:** Via babel and jest tooling
- **Fix:** npm will auto-fix on `npm install` if lock files are updated; run `npm audit fix`

### DEP-003: browserslist Unbounded Memory Growth & Crash
- **Severity:** P2 (HIGH)
- **Category:** CVE (DoS / Memory Exhaustion)
- **Package:** browserslist
- **Affected Projects:** Source/Backend, Source/Frontend, portal/Frontend
- **Vulnerable Range:** ≤4.28.6
- **CVEs:**
  - GHSA-c83g-rgw3-j3cx: Unbounded memory growth via distinct query results (7.5 CVSS)
  - GHSA-73wf-gq98-2v4g: Uncaught crash via untrusted browserslist-stats.json (7.5 CVSS)
- **CVSS:** 7.5 (both)
- **CWE:** CWE-248 (Uncaught Exception), CWE-770 (Allocation of Resources Without Limits)
- **Impact:** If an attacker controls `browserslist-stats.json` or can trigger distinct query patterns, they can crash the build or CI/CD pipeline. Affects dev and build environments primarily.
- **Indirect Dependency:** Via vite, babel
- **Fix:** Update vite to ≥5.x; run `npm audit fix`
- **Note:** Build-time only; not a runtime risk for deployed code

### DEP-004: path-to-regexp ReDoS
- **Severity:** P2 (HIGH)
- **Category:** CVE (Regular Expression DoS)
- **Package:** path-to-regexp
- **Affected Projects:** platform/orchestrator, portal/Backend
- **Vulnerable Range:** <0.1.13
- **CVE:** GHSA-37ch-88jc-xwx2
- **CVSS:** 7.5 / High
- **CWE:** CWE-1333 (Inefficient Regular Expression Complexity)
- **Impact:** Route patterns with multiple parameters can cause catastrophic regex backtracking, leading to denial of service. Attacker crafts URLs that consume CPU and block the server.
- **Affected Code Paths:** Any express route handler using dynamic segments (`:id`, `:param`)
- **Fix:** Upgrade express and its dependencies; run `npm audit fix`
- **Cross-ref:** [CROSS-REF: red-teamer] — This is exploitable in production if exposed to untrusted input

### DEP-005: form-data CRLF Injection
- **Severity:** P2 (HIGH)
- **Category:** CVE (Injection)
- **Package:** form-data
- **Affected Projects:** Source/Frontend, portal/Frontend
- **Vulnerable Range:** 4.0.0–4.0.5
- **CVE:** GHSA-hmw2-7cc7-3qxx
- **CVSS:** 7.5 / High
- **CWE:** CWE-93 (Improper Neutralization of CRLF Sequences in HTTP Headers)

- **Fix:** Update form-data to ≥4.0.6; run `npm audit fix`
