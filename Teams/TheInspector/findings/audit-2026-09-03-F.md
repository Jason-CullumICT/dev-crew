## Critical Vulnerabilities (P1)

### DEP-001: Handlebars.js JavaScript Injection (Source/Backend)
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / Remote Code Execution
- **Package:** handlebars (transitive, via build tools)
- **Affected Versions:** >=4.0.0 <=4.7.8
- **File:** Source/Backend/package-lock.json
- **CVE IDs:**
  - GHSA-2w6w-674q-4c4q (CVSS 9.8): JavaScript Injection via AST Type Confusion
  - GHSA-3mfm-83xf-c92r (CVSS 8.1): JavaScript Injection via @partial-block tampering
  - GHSA-xhpv-hc6g-r9c6 (CVSS 8.1): JavaScript Injection via dynamic partial object
  - GHSA-9cx6-37pm-9jff (CVSS 7.5): DoS via malformed decorator syntax

**Detail:** Handlebars template engine contains multiple JavaScript injection vulnerabilities allowing arbitrary code execution through malformed template inputs. CVSS score 9.8 indicates critical severity with network-accessible attack vector and no authentication required.

**Fix:** `npm update handlebars` → upgrade to >=4.7.9  
**Cross-ref:** [ESCALATE → TheGuardians] — RCE vulnerability with CVSS 9.8; if templates are user-supplied or rendered from untrusted sources, immediate patching required.

### DEP-002: Vitest Arbitrary File Read & Execution (portal/Backend, portal/Frontend)
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / Path Traversal + RCE
- **Package:** vitest (direct dependency in dev environment)
- **Affected Versions:** <3.2.6
- **File:** portal/Backend/package.json, portal/Frontend/package.json
- **CVE ID:** GHSA-5xrq-8626-4rwp (CVSS 9.8)

**Detail:** When Vitest UI server is listening (e.g., during development with `vitest --ui`), an attacker can read arbitrary files from the filesystem and execute arbitrary code. The vulnerability affects the development server, not production builds.

**Impact:** Any developer machine with Vitest UI enabled is compromised. Source code, environment files (.env), private keys, and arbitrary commands can be accessed/executed by network attackers.

**Fix:** `npm update vitest` → upgrade to >=3.2.6 or >=4.1.11 (major version available)  
**Note:** This is a direct dependency; upgrade is critical.  
**Cross-ref:** [ESCALATE → TheGuardians] — RCE in development environment; developers should immediately patch or disable Vitest UI.

- **Severity:** P2 (HIGH)
- **Category:** CVE / Denial of Service
- **Package:** brace-expansion (transitive)
- **Affected Versions:** <=1.1.17
- **CVEs:**
  - GHSA-f886-m6hf-6m8v (CVSS 6.5): Zero-step sequence causes process hang/memory exhaustion
  - GHSA-3jxr-9vmj-r5cp (CVSS 5.3): Exponential-time expansion DoS
  - GHSA-mh99-v99m-4gvg (CVSS 7.5): Unbounded expansion causes OOM crash

**Detail:** Input sequences like `{a..{b..c}}` cause exponential expansion, exhausting memory and hanging the process.

**Fix:** `npm update brace-expansion` → upgrade to >=1.1.18  
**Note:** This is a transitive dependency; check which direct dependency includes it.
