## Detailed Findings by Category

### 1. CRITICAL VULNERABILITIES (P1)

#### DEP-001: Handlebars JavaScript Injection via AST Type Confusion
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / Code Execution
- **Package:** `handlebars@4.7.8`
- **File:** `Source/Backend/package-lock.json`
- **Affected Versions:** 4.0.0 - 4.7.8
- **Fixed in:** 4.7.9+
- **CVE ID:** GHSA-2qvq-rjwj-gvw9
- **CVSS Score:** 9.8 (Critical)
- **CWE:** CWE-94 (Code Injection), CWE-843 (Type Confusion)

**Detail:** 
Handlebars.js has multiple JavaScript Injection vulnerabilities via AST Type Confusion when processing `@partial-block` and dynamic partials. An attacker can inject and execute arbitrary JavaScript code through specially crafted templates.

**Impact:** Remote Code Execution (RCE) in template rendering context
**Fix:** 
```bash
cd Source/Backend && npm update handlebars
```

**Cross-ref:** [ESCALATE → TheGuardians] - This is a direct RCE vulnerability affecting template rendering infrastructure.

#### DEP-002: Vitest Arbitrary File Read & Execution (UI Server)
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / Information Disclosure & Code Execution
- **Packages:** 
  - `vitest@2.1.9` (Source/Frontend)
  - `vitest@1.6.1` (portal/Backend, portal/Frontend)
- **Files:** 
  - `Source/Frontend/package-lock.json`
  - `portal/Backend/package-lock.json`
  - `portal/Frontend/package-lock.json`
- **Affected Versions:** < 3.2.6
- **Fixed in:** 3.2.6+
- **CVE ID:** GHSA-5xrq-8626-4rwp
- **CVSS Score:** 9.8 (Critical)
- **CWE:** CWE-22 (Path Traversal), CWE-862 (Missing Authorization)

**Detail:** 
When the Vitest UI server is running and listening, attackers can read arbitrary files from the filesystem and potentially execute code without authentication. This is a critical security issue for development and CI/CD environments.

**Impact:** 
- Arbitrary file read/disclosure of sensitive data
- Potential code execution if combined with other vulnerabilities
- Affects all three instances where vitest is used

**Fix:**
```bash
# Source/Frontend - requires major version upgrade
cd Source/Frontend && npm install vitest@latest
# (Will upgrade to 5.0.0+)

# portal/Backend & portal/Frontend
cd portal/Backend && npm install vitest@latest
cd portal/Frontend && npm install vitest@latest
```

**Mitigation (SHORT TERM):** 
- Do NOT expose Vitest UI server to untrusted networks
- Disable Vitest UI in production builds and CI environments
- Restrict network access to localhost only

**Cross-ref:** [ESCALATE → TheGuardians] - Critical information disclosure and potential RCE.

#### DEP-003: protobufjs Arbitrary Code Execution (Multiple Issues)
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / Code Execution
- **Package:** `protobufjs@7.5.4`
- **File:** `portal/Backend/package-lock.json`
- **Affected Versions:** <= 7.5.4
- **Fixed in:** 7.5.5+
- **Primary CVE ID:** GHSA-xq3m-2v4x-88gg
- **CVSS Score:** 9.8 (Critical)
- **CWE:** CWE-94 (Code Injection)

**Detail:** 
protobufjs has multiple critical code injection vulnerabilities:
1. **Arbitrary code execution** via unsafe code generation
2. **Code injection through bytes field defaults** in generated toObject code
3. **Prototype injection** via constructor injection
4. **Unbounded recursion DoS** via recursive proto definitions

An attacker can craft malicious Protocol Buffer definitions or messages to execute arbitrary code during deserialization.

**Impact:** Remote Code Execution in proto message processing
**Fix:**
```bash
cd portal/Backend && npm update protobufjs
```

**Cross-ref:** [ESCALATE → TheGuardians] - Critical RCE via protocol buffer parsing.
