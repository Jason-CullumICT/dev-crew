## Critical Vulnerabilities (P1 - Immediate Action Required)

### DEP-001: Prototype Pollution RCE in Tinypool
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / RCE
- **Package:** tinypool <=2.1.1 (transitive via vitest)
- **Affected Projects:** Frontend, Portal-FE
- **CVE ID:** GHSA-5gmw-xhrv-c9v3, GHSA-85c8-ppgw-ccpr
- **Title:** Prototype Pollution gadget in worker options leads to Remote Code Execution
- **Risk:** Remote attacker can execute arbitrary code via prototype pollution in worker pool options
- **CVSS Score:** High (Unauthenticated, network-exploitable)
- **Fix:** `npm audit fix --force` to upgrade vitest to >=5.0.5
- **Status:** Fix available (requires breaking change)
- **Cross-Ref:** [ESCALATE → TheGuardians] - RCE vulnerability requires immediate security review

### DEP-002: IP Spoofing via IPv4-mapped IPv6 in proxy-addr
- **Severity:** P1 (CRITICAL)
- **Category:** CVE / Access Control Bypass
- **Package:** proxy-addr <2.0.8 (transitive via Express middleware)
- **Affected Projects:** Backend
- **CVE ID:** GHSA-jqcg-44mw-7w3h
- **Title:** proxy-addr vulnerable to IP spoofing via IPv4-mapped IPv6 trust subnet
- **Risk:** Attacker can forge source IP via IPv4-mapped IPv6 addresses, bypassing IP-based access controls
- **CVSS Score:** Critical (9.1 - could bypass all IP-based security)
- **Impact:** If application relies on IP whitelisting or source IP validation, this is exploitable
- **Fix:** `npm audit fix` to upgrade proxy-addr to >=2.0.8
- **Status:** Fix available
- **Cross-Ref:** [ESCALATE → TheGuardians] - Access control bypass

### DEP-003: Handlebars.js JavaScript Injection (Multiple CVEs)
- **Severity:** P1 (CRITICAL - 10 distinct vulnerabilities)
- **Category:** CVE / Code Injection
- **Package:** handlebars <=4.7.7 (transitive, deep dependency via tooling)
