### Critical Findings (P1/P2)

#### DEP-001: Body-Parser Denial of Service (HIGH)

- **Severity:** P2 (High, transitive dependency)
- **Category:** cve
- **Package:** body-parser@1.20.8
- **File:** Source/Backend/package-lock.json
- **Vulnerability:** GHSA-27r3-jxmh-p828 — Trailing bytes after compressed request body bypass size enforcement
- **CVSS Score:** 7.5 (High)
- **CWE:** CWE-248 (Uncaught Exception)
- **Affected Versions:** body-parser < 1.20.9
- **Description:** body-parser fails to properly validate compressed request bodies. An attacker can craft a request with trailing bytes after the compressed payload that bypass the size limit check, leading to DoS.
- **Fix:** `npm update body-parser` (requires express or middleware bump)
- **Exploitability:** HIGH — Can be triggered via HTTP POST with Content-Encoding: gzip + crafted body

#### DEP-002: Brace-Expansion Multiple DoS Vulnerabilities (CRITICAL)
- **Severity:** P1 (Multiple critical DoS vectors, transitive)
- **Category:** cve
- **Package:** brace-expansion (dep chain from build tools)
- **File:** Source/Backend/package-lock.json
- **Vulnerabilities:** 
  - GHSA-3jxr-9vmj-r5cp — Exponential-time expansion (CVSS 5.3)
  - GHSA-mh99-v99m-4gvg — Unbounded expansion causing OOM (CVSS 7.5)
  - GHSA-rgw5-rvv9-x895 — Bypass of prior mitigation (CVSS 7.5)
  - GHSA-q2hr-2g5m-vwhr — Quadratic-time rewrite (CVSS 5.3)
- **Description:** brace-expansion is vulnerable to multiple denial-of-service attacks that can exhaust CPU or memory. Crafted brace patterns like `{a},{a}...{a}` can cause exponential expansion or recursion stack overflow.
- **Attack Vector:** Indirect via build tools (globbing patterns) or if the package is directly exposed to user input
- **Fix:** Update transitive dependency (check which package uses brace-expansion)
- **Notes:** Build-time attack vector is limited; runtime risk depends on whether app uses brace-expansion directly

#### DEP-003: Browserslist Unbounded Memory Growth (HIGH)
- **Severity:** P2 (High, transitive dependency)
- **Category:** cve
- **Package:** browserslist@4.28.6 or older
- **File:** Source/Backend/package-lock.json, Source/Frontend/package-lock.json
- **Vulnerability:** GHSA-c83g-rgw3-j3cx — Cache without eviction policy causes OOM
- **CVSS Score:** 7.5 (High)
- **CWE:** CWE-770 (Allocation of Resources Without Limits)
- **Description:** browserslist caches query results without a size limit. An attacker controlling browser list queries can cause unbounded memory growth, eventually triggering OOM.
- **Fix:** `npm update browserslist`
- **Impact:** Medium — Mostly affects build-time; runtime risk if browserslist API is exposed

#### DEP-004: Portal/Backend OpenTelemetry Critical Issues (CRITICAL)
- **Severity:** P1 (4 critical vulnerabilities)
- **Category:** cve
- **Package:** @opentelemetry/auto-instrumentations-node and ecosystem
- **File:** portal/Backend/package.json
- **Issues:** 25 known issues in auto-instrumentations; multiple versions of OpenTelemetry packages with overlapping CVEs
- **Description:** The portal's instrumentation layer has a high concentration of CVEs in protobufjs (12 issues) and OpenTelemetry (25 total issues).
- **Risk:** ESCALATE → TheGuardians (if telemetry data contains sensitive info)
- **Fix:** Audit and pin OpenTelemetry versions; consider alternative instrumentation

#### DEP-005: PostCSS Path Traversal / Information Disclosure (HIGH)
- **Severity:** P2 (High, transitive via build tools)
- **Category:** cve
- **Package:** postcss (dependency chain in Frontend)
- **Vulnerability:** GHSA-6g55-p6wh-862q — Uncontrolled sourceMappingURL loading via CSS
- **CVSS Score:** 7.5
- **CWE:** CWE-22 (Path Traversal)
- **Description:** postcss auto-loads source maps via CSS `sourceMappingURL` comments without validation. An attacker can supply malicious CSS that reads arbitrary files or information disclosure.
- **Fix:** Update postcss; validate CSS sources
- **Impact:** Medium-High if the app processes untrusted CSS

#### DEP-006: React Router Open Redirect (MODERATE)
- **Severity:** P3 (Moderate, transitive via react-router-dom)
- **Category:** cve
- **Package:** @remix-run/router@1.3.0 to 1.23.2
- **File:** Source/Frontend/package-lock.json
- **Vulnerability:** GHSA-2j2x-hqr9-3h42 — Protocol-relative URL confusion in same-origin redirect
- **CWE:** CWE-601 (Open Redirect)
- **Description:** React Router treats URLs starting with `//` as same-origin when they should be treated as protocol-relative (which can redirect to external sites).
- **Fix:** `npm update @remix-run/router` or `react-router-dom`
- **Impact:** Low-Medium — Requires app to trust user input in redirects

#### DEP-007: Vite Build Tool Vulnerabilities (MODERATE)
- **Severity:** P3 (Moderate, dev dependency)
- **Category:** cve
- **Package:** vite (used in Source/Frontend, portal/Frontend, portal/Backend)
- **File:** Multiple package-lock.json files
- **Issues:** 9 known vulnerabilities across Vite versions
- **Description:** Vite has multiple CVEs related to path traversal in dev server and build process.
- **Fix:** Update to latest stable Vite version (currently ~5.x)
- **Impact:** Build-time / dev-only; runtime impact depends on configuration

#### DEP-008: Vitest Mocker Path Traversal / Code Injection (MODERATE)
- **Severity:** P3 (Moderate, dev/test dependency)
- **Category:** cve
- **Package:** @vitest/mocker (indirect dependency)
- **Vulnerability:** 
  - GHSA-82fw-gwwq-j7x9 — Path traversal via redirect mocking
  - GHSA-qxg6-89mg-rqv8 — Arbitrary code injection via mock registration
- **CWE:** CWE-22 (Path Traversal), CWE-94 (Code Injection)
- **Description:** Vitest's mocking system can be abused to read arbitrary files or inject code via manual mock registration.
- **Fix:** Upgrade vitest to 4.1.12+
- **Impact:** Test-time attack; could affect CI/CD security if tests run untrusted code
