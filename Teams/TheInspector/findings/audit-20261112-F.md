## Detailed Findings by Severity

### P1: CRITICAL VULNERABILITIES (Immediate Fix Required)

#### DEP-001: vitest — Direct Dependency RCE
- **Severity:** P1 (Critical)
- **Category:** cve
- **Package:** vitest@<=4.1.10
- **Files:** Source/Frontend/package.json
- **CVE:** GHSA-5xrq-8626-4rwp (CVSS 9.8)
- **Detail:** When Vitest UI server is listening, arbitrary files can be read and executed without authentication. Affects all versions ≤4.1.10. This is a **direct dependency** in Frontend.
- **Impact:** Remote code execution, information disclosure
- **Fix:** `npm update vitest` to >=3.2.6 or >=4.1.11 or >=5.1.0
- **Timeline:** CRITICAL — Deploy fix immediately before running tests

#### DEP-002: handlebars — JavaScript Injection RCE
- **Severity:** P1 (Critical)
- **Category:** cve
- **Package:** handlebars@>=4.0.0 <=4.7.9
- **Files:** Source/Backend/package.json, Source/Frontend/package.json (transitive)
- **CVEs:** 
  - GHSA-2w6w-674q-4c4q (CVSS 9.8) — AST Type Confusion RCE
  - GHSA-8r5x-fm3f-whwj (CVSS 9.8) — AST Type Confusion bypass
  - GHSA-p8wg-vrv2-v86f (CVSS unknown) — Own property bypass
- **Detail:** Multiple RCE vectors via template injection and prototype pollution. Affects all 4.x versions up to 4.7.9.
- **Impact:** Remote code execution, server compromise
- **Fix:** Update to handlebars@>=5.0.0 or >=4.7.10
- **Timeline:** CRITICAL — Test thoroughly before deploying

#### DEP-003: proxy-addr — IP Spoofing (Trust Subnet Bypass)
- **Severity:** P1 (Critical)
- **Category:** cve
- **Package:** proxy-addr@>=1.1.0 <2.0.8
- **Files:** Source/Backend/package.json, platform/orchestrator/package.json (transitive via express)
- **CVE:** GHSA-jqcg-44mw-7w3h (CVSS 9.1)
- **Detail:** IPv4-mapped IPv6 addresses can bypass trust subnet checks. Allows attackers to spoof trusted IPs. This affects Express.js deployments with `trust proxy` settings.
- **Impact:** Authentication bypass, IP-based access control bypass
- **Fix:** `npm update proxy-addr` to >=2.0.8
- **Cross-ref:** [ESCALATE → TheGuardians] — Direct impact on authentication trust

#### DEP-004: protobufjs — Arbitrary Code Execution
- **Severity:** P1 (Critical)
- **Category:** cve
- **Package:** protobufjs@>=7.0.0 <7.5.5
- **Files:** platform/orchestrator/package.json (transitive)
- **CVE:** GHSA-xq3m-2v4x-88gg (CVSS 9.8)
- **Detail:** Code generation gadget after prototype pollution. Malformed .proto files or untrusted protobuf messages can lead to RCE. Multiple related CVEs (GHSA-66ff-xgx4-vchm, etc.).
- **Impact:** Remote code execution if processing untrusted protobuf data
- **Fix:** `npm update protobufjs` to >=7.5.5 or >=7.6.5
- **Timeline:** CRITICAL if processing external protobuf messages

#### DEP-005: tinypool — Prototype Pollution RCE
- **Severity:** P1 (Critical)
- **Category:** cve
- **Package:** tinypool@<=2.1.1
- **Files:** Source/Frontend/package.json (transitive via vitest)
- **CVEs:** 
  - GHSA-5gmw-xhrv-c9v3 (prototype pollution in worker options)
  - GHSA-85c8-ppgw-ccpr (prototype pollution in run() options)
- **Detail:** Malicious worker options can trigger prototype pollution leading to RCE. This is a transitive dep via vitest.
- **Impact:** Remote code execution during test execution
- **Fix:** Update vitest to >=5.1.0 (which pulls tinypool >=2.1.2)

#### DEP-006: Portal/Backend — 4 Critical OpenTelemetry Issues
- **Severity:** P1 (Critical)
- **Category:** cve
- **Package:** Multiple @opentelemetry/* packages
- **Files:** portal/Backend/package.json
- **Detail:** Portal/Backend has 61 vulnerabilities (4 critical, 11 high, 46 moderate). This is an extremely high-risk dependency graph. OpenTelemetry instrumentation packages have multiple moderate vulnerabilities.
- **Impact:** Information disclosure, DoS, potential RCE
- **Fix:** Review and update all @opentelemetry/* packages to latest versions
- **Note:** Portal is NOT part of source application per CLAUDE.md, but presents lateral movement risk

### P2: HIGH VULNERABILITIES (Urgent - Deploy within Sprint)

#### DEP-007: @grpc/grpc-js — Server Crash DoS
- **Severity:** P2 (High)
- **Category:** cve
- **Package:** @grpc/grpc-js@>=1.14.0 <1.14.5
- **Files:** platform/orchestrator/package.json (transitive)
- **CVEs:** 
  - GHSA-5375-pq7m-f5r2 (CVSS 7.5) — Malformed request crash
  - GHSA-99f4-grh7-6pcq (CVSS 7.5) — Malformed compressed message crash
  - GHSA-m9gg-hp2v-232j (CVSS 7.4) — getAuthContext authorization bypass
- **Detail:** Malformed gRPC messages can crash the server. TLS cert validation can be bypassed.
- **Impact:** Service availability, authentication bypass
- **Fix:** Update @grpc/grpc-js to >=1.14.5

#### DEP-008: body-parser — Request Size Bypass
- **Severity:** P2 (High)
- **Category:** cve
- **Package:** body-parser@* (transitive via express)
- **Files:** Source/Backend/package.json
- **CVE:** GHSA-v422-hmwv-36x6 (CVSS 3.7 but classified high)
- **Detail:** Invalid limit values silently disable size enforcement, allowing unbounded request processing.
- **Impact:** DoS via large request payloads
- **Fix:** Update to latest body-parser version

#### DEP-009: form-data — ReDoS & Path Traversal
- **Severity:** P2 (High)
- **Category:** cve
- **Package:** form-data@*
- **Files:** Source/Backend (transitive), Source/Frontend (transitive)
- **Detail:** Multiple vulnerabilities including ReDoS and potential path traversal
- **Impact:** DoS, information disclosure
- **Fix:** Update form-data to latest

#### DEP-010: React Router — Open Redirect via Protocol-Relative URL
- **Severity:** P2 (Moderate → High in production)
- **Category:** cve
- **Package:** @remix-run/router@>=1.3.0 <1.23.3
- **Files:** Source/Frontend/package.json
- **CVE:** GHSA-2j2x-hqr9-3h42 (CVSS unspecified, medium severity)
- **Detail:** Same-origin redirects with path starting `//` can be hijacked via protocol-relative URL reinterpretation.
- **Impact:** Open redirect, phishing, session hijacking
- **Fix:** Update react-router-dom to >=6.28.0 (pulls @remix-run/router >=1.23.3)
